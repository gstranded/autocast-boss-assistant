Boss 海投助手 — 使用教程

BOSS 直聘网页端的职位筛选、投递确认、分段消息和简历发送助手

第 1 / 13 步
0

片头

~5 秒

画面操作

  • 显示项目 Logo + 标题 "Boss 海投助手 — 使用教程"
  • 可加一行副标题："BOSS 直聘批量沟通助手"

大家好，今天带大家快速上手 Boss 海投助手。这是一款 BOSS 直聘网页端的职位筛选、批量沟通和简历发送助手。看完这个教程，你就能在 3 分钟内完成配置并开始使用。

1

下载与安装

~40 秒

画面操作

  • 打开浏览器，访问 github.com/gstranded/autocast-boss-assistant
  • 点击右侧 Releases 链接
  • 下载最新的 autocast-boss-haitou-vX.Y.Z.zip
  • 解压 ZIP 文件到本地文件夹
  • 打开 Chrome，地址栏输入 chrome://extensions 回车
  • 打开右上角 开发者模式 开关
  • 点击 加载已解压的扩展程序
  • 选择解压后的 extension 文件夹

首先，打开 GitHub 仓库，点击 Releases，下载最新版本的压缩包。下载完成后解压到任意文件夹。

接着打开 Chrome 浏览器，在地址栏输入 chrome://extensions 回车。打开右上角的"开发者模式"开关，然后点击"加载已解压的扩展程序"，选择刚才解压出来的 extension 文件夹。

看到扩展列表中出现 Boss 海投助手的图标，就说明安装成功了。

提示：Edge 用户打开 edge://extensions，操作完全相同。
2

打开面板

~15 秒

画面操作

  • 打开 BOSS 直聘职位列表页 www.zhipin.com/web/geek/jobs
  • 确保已登录账号
  • 按 F5 刷新页面
  • 点击页面右侧出现的 蓝色悬浮按钮
  • 侧边面板滑出，显示"任务"标签页

安装好之后，打开 BOSS 直聘的职位列表页，确保你已经登录。刷新一下页面，你会看到页面右侧出现一个蓝色的悬浮按钮。点击它，侧边面板就会滑出来，这就是我们的操作界面。

提示：如果面板显示"未连接页面"，确认网址属于 zhipin.com，然后按 F5 刷新。
3

配置筛选条件

~60 秒
筛选页 — 配置职位、地点、薪资等过滤条件

画面操作

  • 点击面板顶部的 筛选 标签页
  • "职位名称：包含任意"填写 Java, Go, 后端
  • "职位名称：排除任意"填写 外包, 驻场, 代招
  • "地点包含"填写 广州, 深圳
  • "最低月薪"填写 15000
  • 勾选 排除猎头 和 排除外包/驻场
  • （可选）"公司排除"填写不想投的公司关键词

第一步，我们来配置筛选条件。点击顶部的"筛选"标签。

在"职位名称：包含任意"里填上你想找的职位关键词，多个关键词用逗号隔开，比如 Java、Go、后端，命中任意一个就会通过。

在"排除任意"里填上你不想看到的词，比如外包、驻场、代招，包含这些词的岗位会被自动跳过。

接着设置目标城市，在"地点包含"里填写，比如广州、深圳。再设一个最低月薪，比如 15000，薪资低于这个数的岗位也会被过滤掉。

建议勾选"排除猎头"和"排除外包/驻场"，这两个默认是开启的。如果你还有特别不想投的公司，可以在"公司排除"里加上关键词。

4

配置消息模板

~45 秒
消息页 — 配置分段消息和发送模式

画面操作

  • 点击 消息 标签页
  • 发送模式选择 自动识别（推荐）
  • 第 1 段填写：您好，我对贵司的这个岗位很感兴趣，方便进一步沟通吗？
  • 第 2 段填写：我有多年的相关经验，期待与您详聊。
  • 段间等待时间设为 3 秒

第二步，配置消息模板。点击"消息"标签。

发送模式建议选择"自动识别"，它会自动检查当前对话是否已经发过第一段消息，避免重复发送。

在第 1 段里写上你的打招呼语，比如"您好，我对贵司的这个岗位很感兴趣，方便进一步沟通吗？"

第 2 段可以写一句跟进语，比如"我有多年的相关经验，期待与您详聊。"

段间等待时间建议设 3 秒左右，让消息发送看起来更自然。

5

配置简历方案

~30 秒

画面操作

  • 点击 简历 标签页
  • 点击上传区域，选择简历截图作为 图片简历
  • 发送时机选择 文本发送完成后立即发送

第三步，配置简历。点击"简历"标签。

上传一张图片简历后，插件会在沟通文本确认成功后自动发送。BOSS 自带的“发简历”通常要招聘者先回复后才开放，因此插件不再自动点击它。

发送时机建议选择"文本发送完成后立即发送"，这样消息和简历会连贯地发出去。

6

调整安全设置

~30 秒
设置页 — 配置沟通上限和安全参数

画面操作

  • 点击 设置 标签页
  • 将"本次最多沟通"改为 1（首次测试用）
  • 确认"每日最多沟通"为 80
  • 确认"同公司每天最多"为 3
  • 确认"连续失败暂停"为 3

第四步，调整安全设置。点击"设置"标签。

第一次使用，强烈建议把"本次最多沟通"改成 1，先测试一份，确认一切正常后再提高上限。

其他参数保持默认就好：每日最多 80 个沟通，同公司每天最多 3 个，连续失败 3 次自动暂停。这些限制都是为了保护你的账号安全。

7

扫描预览

~30 秒
任务页 — 扫描预览结果，勾选目标岗位

画面操作

  • 点击 任务 标签页，回到主界面
  • 确保 BOSS 直聘职位列表页已打开
  • 点击 扫描预览 按钮
  • 等待扫描完成，查看结果列表
  • 绿色 = 通过，红色 = 排除（附原因）
  • 用复选框勾选你想投递的岗位

配置完成后，回到"任务"标签页。确保你的 BOSS 直聘职位列表页是打开的，然后点击"扫描预览"。

插件会读取当前页面的职位信息，按照你设置的筛选条件逐个检查。通过的岗位会显示为绿色，被排除的会显示红色并标注原因，比如"职位名称不匹配"或"薪资低于下限"。

仔细看一下结果，用复选框勾选你确认要投递的岗位。

8

投递一份测试

~30 秒

画面操作

  • 勾选一个通过的岗位
  • 点击 投递一份测试 按钮
  • 观察插件自动打开聊天窗口
  • 观察消息是否成功发送
  • 观察简历是否正确发出
  • 查看面板底部的状态汇报：成功 / 跳过 / 失败

现在我们来测试一下。勾选一个通过的岗位，然后点击"投递一份测试"。

插件会自动打开对应的聊天窗口，发送你配置的消息，然后发送简历。你在旁边看着就好，不需要手动操作。

发送完成后，面板底部会汇报结果：成功、跳过、失败各几个。如果显示成功 1，说明整个流程没问题。

重要：首次使用务必先测试一份！确认消息内容、收件人和简历都正确后，再进行批量操作。
9

正式批量投递

~20 秒

画面操作

  • 回到 设置 页，将"本次最多沟通"改为 10
  • 回到 任务 页，点击 扫描预览 重新扫描
  • 勾选要投递的岗位，或点击 全选通过项
  • 点击 确认投递

测试通过后，回到设置页，把"本次最多沟通"改成你想要的数量，比如 10 个。

然后回到任务页，重新扫描预览，勾选要投递的岗位，也可以直接点"全选通过项"一键全选。确认无误后，点击"确认投递"，插件就会开始批量处理了。

10

任务控制与监控

~20 秒

画面操作

  • 展示任务运行中的面板状态
  • 依次指出 暂停、继续、跳过当前、停止 按钮
  • 展示下方日志区域的实时输出

任务运行过程中，你可以随时控制。点"暂停"会在当前安全步骤结束后停下来；点"继续"从暂停处恢复；"跳过当前"会跳过正在处理的岗位；"停止"会完全结束任务并汇报统计。

下方的日志区域会实时显示每一步的操作详情，方便你排查问题。

11

导入导出配置

~15 秒

画面操作

  • 在 设置 页点击 导出 JSON
  • 展示下载的 JSON 文件
  • 点击 导入 JSON 选择文件恢复配置

最后一个小技巧：在设置页可以导出和导入配置。导出会把你所有的筛选、消息、简历和设置保存成一个 JSON 文件，下次使用时导入就能一键恢复，非常方便。注意导出文件可能包含图片简历数据，不要公开上传。

12

片尾

~10 秒

画面操作

  • 显示项目 Logo + GitHub 仓库地址
  • 加上 "Star 支持一下" 的提示

以上就是 Boss 海投助手的完整使用教程。记住三个原则：先测试再批量、保持保守上限、不要无人看管运行。如果觉得好用，欢迎到 GitHub 给个 Star。有问题可以提 Issue，我们下期见！
