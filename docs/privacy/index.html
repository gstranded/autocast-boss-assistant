更新日期：2026-09-07　生效日期：2026-09-07

一、我们处理哪些数据

  • 仅存于本机：简历内容与简历图片、岗位筛选规则、消息模板、投递历史与统计、任务进度、扩展设置——全部保存在浏览器本地的 chrome.storage.local 中。
  • 不上传服务器：以上数据不会离开你的设备，我们没有也不会搭建任何收集数据的服务器。
  • 自动化操作：扩展在 BOSS 直聘（zhipin.com / bosszhipin.com）页面内代表你执行「扫描职位、发起沟通、发送消息」等操作，这些操作与你在浏览器中手动点击的效果一致，操作内容即是你配置的消息与简历。
  • 版本检查：扩展设置页「检查更新」功能会向 GitHub 公开接口请求最新版本号（不包含任何个人信息，仅返回版本信息）；无其他网络请求。

二、数据用途

  • 在 BOSS 直聘上完成「筛选职位 → 批量沟通 → 发送消息/简历」的自动化流程，仅用于你本人求职。
  • 任何数据均不用于广告、画像或第三方共享。

三、权限说明

  • storage / unlimitedStorage：本地存储简历、设置与历史。
  • tabs / scripting：在 BOSS 页面注入内容脚本、定位职场列表与消息页。
  • alarms：定时投递的时间窗口调度。
  • windows：左右分屏窗口布局。
  • zhipin.com / bosszhipin.com 域名权限：仅在 BOSS 直聘相关域名运行。

四、数据保留与删除

  • 数据仅存于你的浏览器本地，删除方式：清除浏览器站点数据 / 卸载扩展 / 设置页「清空数据」；卸载扩展后本地数据随浏览器清除机制移除。
  • 导出功能仅将本地数据导出为 JSON 文件，由你自己保管。

五、联系方式

  • 隐私相关问题请通过项目仓库提交：gstranded/autocast-boss-assistant（GitHub Issues）。
