## 第 1 步：加载扩展（约 30 秒）

1. 确认 ego lite 窗口停留在 `chrome://extensions` 页面（如果没看到，地址栏输入 `chrome://extensions` 回车）。
2. 确认右上角「开发者模式」开关是**开启**状态（蓝色）。
3. 点击左上角「**加载未打包的扩展程序**」按钮。
4. 在弹出的文件选择窗口中，按下 `Cmd + Shift + G`，粘贴路径：
   ```
   /Users/gaohaizhen/Desktop/boss/extension
   ```
5. 回车 → 点击「选择」。
6. 页面出现 **AutoCast-Boss海投助手** 卡片（粉色公文包图标，版本 1.7.2）即成功。

> 如果卡片显示「错误」，点开错误详情发给我，我帮你排查。

## 第 2 步：登录测试号（约 1 分钟）

1. 新开一个标签页（`Cmd + T`），打开：
   ```
   https://www.zhipin.com/web/geek/jobs
   ```
2. 点击页面右上角「登录」，用**测试号**扫码登录（不要用主号）。
3. 登录成功后确认：页面出现「推荐职位」列表，右上角显示你的头像/昵称。

> 确认方式：登录后职位列表页右下角应该出现**粉色圆形悬浮按钮**（扩展的），说明扩展已生效。

## 如果遇到问题

| 现象 | 处理 |
|---|---|
| 「加载未打包的扩展程序」按钮灰色/不可点 | 检查开发者模式是否开启 |
| 选择目录后提示清单错误 | 确认选的是 `extension` 目录（里面有 `manifest.json`），不是仓库根目录 |
| 职位页没有悬浮按钮 | 按 `F5` 刷新页面；确认扩展卡片上「此站点可以读取和更改网站数据」为"在所有网站上" |
| 测试号没岗位数据 | 登录后在搜索框搜索「AI」「大模型」等关键词，产生列表数据 |
| 一切正常但想重新开始 | 不用重装，刷新页面即可 |
