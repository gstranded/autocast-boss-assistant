## 配音信息

- 音色：macOS 系统 TTS「婷婷」（Tingting）——系统自带可用音色中唯一正常工作的中文音色（Reed/Flo/Eddy 等增强音色未下载，生成空音频）
- 语速：180 字/分钟
- 段落：17 句，与画面时间轴对齐（基于画面 OCR 分析的时间线）

## 已知瑕疵（建议后期处理）

1. **开场 0–16s 有 EVCapture 录制工具栏**（"该取语雀Token"等悬浮提示）——可剪掉或打码
2. **系统 TTS 音色较机械**——若想要更自然的 AI 配音：剪映 TTS 按 `字幕.srt` 时间轴重新生成即可（台词文本见 `06-逐字稿.md`）
3. 视频有**扫码登录画面**——确认无个人信息后可用
4. 结尾 233s 处配音句结束于 232.9s，无截断

## 重新生成方法（如需调整）

```bash

python3 scripts/gen_voiceover.py          # 生成 TTS 片段
python3 /tmp/gen_srt.py                    # 重新生成 SRT（脚本在 /tmp，可改路径）
swift scripts/burn_subtitles.swift 录屏.mp4 /tmp/tts/meta.json /tmp/sub-render.mp4   # 烧录字幕
swift /tmp/merge_av.swift                  # 合并配音（改脚本内路径）
```
