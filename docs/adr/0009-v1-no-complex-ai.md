# ADR-0009：V1 不引入复杂 AI，优先确定性能力

- 状态：Accepted
- 日期：2026-07-29
- 决策者：产品 / 研发
- 关联：PRD §4, FR-23, FR-24

## 背景

同类产品已宣传 AI 回复等能力。但 AI 在薪资、到岗时间、学历、经历等事实上一旦说错，会直接伤害求职结果。此外，语义匹配与模型排序会增加成本、失败面与隐私面，分散 V1 对可靠性的投入。

市场分析结论指出：更值得做的差异是预览、可解释、去重、简历正确、任务可控，而不是更激进的自动点击或未校准的全自动 AI。

## 决策

1. **V1 不做**：复杂语义召回、默认全自动 AI 回复、云端大模型必选依赖。
2. **V1 只做确定性系统**：规则筛选、预览、状态机消息、简历策略、防重复、限流、恢复、日志。
3. **V2 可选 AI**：
   - 回复建议默认“生成 → 确认 → 发送”
   - 语义匹配作为规则之后的增强，不替代规则门禁

## 备选方案

1. **V1 就上全自动 AI**：差异表面化，风险高。
2. **永远不做 AI**：可能在后续竞争中缺失辅助能力，故放到 V2 而非永久排除。

## 后果

### 正面

- 研发聚焦稳定性与核心差异
- 降低错误事实输出风险

### 负面 / 风险

- 短期营销上 AI 卖点较弱
- 需靠产品完成度竞争

## 后续动作

- V2 单独立项评估模型来源（用户 API Key / 本地）
