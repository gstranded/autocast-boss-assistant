# ADR-0011：移除 BOSS“发简历”按钮自动化，仅保留图片简历

- 状态：Accepted
- 日期：2026-08-24
- 决策者：产品 / 研发
- 关联：FR-04, ADR-0007

## 背景

BOSS 聊天页的“发简历”按钮通常只有在招聘者回复、形成双向沟通后才可用。自动投递刚创建会话时，该按钮会处于禁用状态或不存在。继续自动查找和点击会把正常的平台门禁误判为“附件简历发送失败”，暂停整个队列。

插件自己的图片简历发送不依赖该按钮，且已有 `IMAGE_SENT` 页面回执与幂等保护。

## 决策

1. 删除“自动点击 BOSS 发简历”设置和 `autoSendAttachmentResume` 运行时字段。
2. 删除 `BHT_SEND_RESUME` 协议、按钮查找、二次确认、平台简历回执和失败处理代码。
3. 升级或导入旧配置时自动清除 `autoSendAttachmentResume`，不影响其他设置。
4. 自动简历发送仅保留图片简历；仍要求文本消息先得到成功回执。
5. 用户在招聘者回复后如需发送 BOSS 在线简历，可在官方聊天页手动操作。

## 后果

- 自动投递不会再因“发简历”按钮受限而失败或暂停。
- 设置页和文档只展示真实可用的图片简历能力。
- 不再对平台按钮开放时机做脆弱的 DOM 猜测。
- 图片简历、多方案绑定、发送顺序、压缩、回执和幂等逻辑保持不变。
