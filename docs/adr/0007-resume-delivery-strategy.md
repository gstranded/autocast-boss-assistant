# ADR-0007：图片/附件简历独立开关与绑定策略

- 状态：Superseded by ADR-0011
- 日期：2026-07-29
- 决策者：产品 / 研发
- 关联：FR-04, FR-05, ADR-0002

## 背景

图片简历与附件简历的使用场景不同：有的 HR 只看聊天图片，有的要求 PDF 附件。单一“自动发送简历”总开关容易造成消息过载或重复投递材料。

多方向求职者还需要按岗位自动选择不同简历版本，否则“简历发错”会直接损害机会。

## 决策

1. **图片简历开关**与**附件简历开关**彼此独立。
2. 默认发送时机：**HR 请求简历后**；“沟通后立即发送”为可选且默认关。
3. 不建议默认同时立即发送图片+附件。
4. 图片多页 **串行保序**，禁止并发上传。
5. 支持多简历档案 + 关键词绑定规则 + 默认档案回退。
6. 文件首次需用户选择；本地持久化；显示版本/更新时间降低旧文件误发。

## 备选方案

1. **单一总开关**：实现简单，控制粒度差。
2. **仅手动发送**：最安全，但无法满足海投辅助目标。
3. **仅云端简历链接**：依赖外链与隐私策略，V1 不采用。

## 后果

### 正面

- 降低材料误发与过载
- 多方向求职可用

### 负面 / 风险

- 配置项变多，需要预设模板
- 本地存储体积管理

## 后续动作

- 绑定规则优先级排序
- 发送前预览“将使用哪份简历”
