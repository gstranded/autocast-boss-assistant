# ADR-0002：本地优先存储与隐私默认

- 状态：Accepted
- 日期：2026-07-29
- 决策者：产品 / 研发
- 关联：FR-04, FR-10, NFR-03, NFR-09

## 背景

简历与投递记录包含手机号、邮箱、教育与工作经历等敏感个人信息。浏览器扩展若默认上传到开发者服务器，会显著增加隐私与合规风险，并降低用户信任。

同时，浏览器无法在未授权时任意读取本地文件系统，简历复用必须建立在用户主动选择与扩展本地持久化之上。

## 决策

1. **本地优先**：配置、消息模板、黑名单、投递历史、任务检查点、简历文件默认只存于扩展本地（`chrome.storage` / IndexedDB 等）。
2. **无默认云同步、无默认自有后端上传**。
3. 导出功能可生成用户手动保管的文件，并提示敏感风险。
4. 若未来提供可选云能力，必须单独同意、可关闭，并另开 ADR。

## 备选方案

1. **自建后端云同步**：多设备方便，但隐私与成本高，V1 不采用。
2. **仅内存不落盘**：刷新即丢，无法恢复任务与防重复，不可接受。

## 后果

### 正面

- 降低隐私风险
- 符合“辅助工具”定位
- 减少后端合规负担

### 负面 / 风险

- 换机/重装需导入导出
- 本地存储配额与体积需管理（多图片简历）

## 后续动作

- FRS 明确导入导出与清理
- 实现层评估 IndexedDB 存简历二进制
