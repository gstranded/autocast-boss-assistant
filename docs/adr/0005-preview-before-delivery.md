# ADR-0005：投递前预览优先于直接自动投递

- 状态：Accepted
- 日期：2026-07-29
- 决策者：产品 / 研发
- 关联：FR-02, G2, NFR-05

## 背景

自动点击“立即沟通”一旦启动，错误规则会在短时间内造成大量误沟通，且难以撤回。同类工具若缺少预览，用户难以建立信任。

产品主张强调“投递前可预览、筛选原因可解释”，预览不是附属功能，而是主路径门禁。

## 决策

1. V1 主路径为：**配置 → 扫描预览 → 用户确认 → 自动执行**。
2. 预览必须给出汇总计数与逐岗原因。
3. 未确认不得批量发送消息/简历。
4. 允许预览阶段手动剔除个别岗位（建议 P0）。
5. 可通过率异常提示（过高/过低）帮助发现配错规则。

## 备选方案

1. **直接海投**：速度最快，误投风险最高，违背差异化。
2. **逐条人工确认**：最安全，但效率低；可作为额外安全档，不替代预览批量确认。

## 后果

### 正面

- 大幅降低误投
- 提升可解释性与信任

### 负面 / 风险

- 多一步操作；需把预览做得足够快

## 后续动作

- 预览扫描支持取消
- 记录“预览确认后的列表快照”再执行，避免执行期列表变化无感知
