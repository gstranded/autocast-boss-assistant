# ADR-0001：采用 ADR 记录架构决策

- 状态：Accepted
- 日期：2026-07-29
- 决策者：产品 / 研发
- 关联：文档体系

## 背景

Boss 海投助手涉及规则引擎、消息去重、简历发送、本地存储、频率限制等多个高耦合决策。口头约定或仅存在于聊天记录中的决策容易漂移，导致实现与产品目标不一致。

## 决策

采用 Architecture Decision Record（ADR）记录重要决策：

1. 存放于 `docs/adr/`
2. 顺序编号，允许 `Superseded` 而不是静默修改历史
3. 与 PRD/FRS 双向链接

## 备选方案

1. **仅维护 PRD**：难表达取舍与否决方案
2. **Wiki/即时消息**：不可追溯、难 code review

## 后果

### 正面

- 决策可审计、可传承
- 新产品争议可回看上下文

### 负面 / 风险

- 需额外维护成本
