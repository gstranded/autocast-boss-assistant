# ADR-0008：频率限制与账号安全边界

- 状态：Accepted
- 日期：2026-07-29
- 决策者：产品 / 研发
- 关联：FR-08, NFR-08, PRD §2.2

## 背景

批量自动沟通天然接近平台风控与消息限额边界。BOSS 用户协议相关公开文本强调平台可限制消息行为，用户不得以干扰服务的方式使用平台。

若产品以“绕过风控/无限海投”为卖点，既违规风险高，也与长期可用相悖。

## 决策

1. 将 **用户可见的速率与数量限制** 作为一等功能，而非隐藏参数。
2. V1 默认保守：
   - 本次最多沟通 30
   - 每日最多沟通 80
   - 同公司每天最多 3
   - 段间/岗间间隔可配
   - 连续失败 3 次自动暂停
3. 检测到平台限制、验证码或异常拦截时：**停止任务并解释**，不提供绕过指导。
4. 产品文案禁止宣传“突破限制”。

## 备选方案

1. **无限制尽快投**：短期爽，长期封限风险高。
2. **固定死间隔不可配**：不够灵活。
3. **自适应绕过策略**：明确拒绝。

## 后果

### 正面

- 降低账号风险
- 符合合规与可信定位

### 负面 / 风险

- 部分用户会觉得“不够猛”
- 需用预览/质量能力证明价值

## 后续动作

- 设置页展示限额剩余
- 达到限额时的引导文案
