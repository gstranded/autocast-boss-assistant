## 产品一句话定位

> 面向 BOSS 直聘求职者的浏览器扩展：在**用户可控**的前提下完成岗位筛选、沟通投递与简历发送，核心差异不是“投得更多”，而是 **投递前可预览、筛选原因可解释、消息不重复、简历不发错、任务随时可控**。

## 版本策略

- **V1（P0）**：确定性规则与任务可靠性，不做复杂 AI
- **V2（P1）**：多方案、漏斗统计、规则解释增强、AI 回复建议、跟进提醒

## 维护约定

1. 需求变更先改 PRD / FRS，再同步 ADR。
2. 涉及架构取舍时新增 ADR，不覆盖旧决策；旧 ADR 标记 `Superseded`。
3. 文档默认中文，标识符可保留英文。
